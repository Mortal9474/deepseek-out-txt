DeepSeek 对话导出工具 - 使用说明
==
【这个工具能做什么？】
把你在 DeepSeek 网页版里的对话导出成 TXT 文本文件，保存到电脑上。

【使用前需要准备什么？】
1. 电脑上要装 Edge 浏览器（Windows 一般自带）。
2. 电脑上要装 Python。如果没装，双击“一键导出.bat”会弹出下载页，
   下载安装时请务必勾选 “Add Python to PATH”。

【文件夹里有什么？】
- 一键导出.bat    → 双击这个启动
- export_chat.py  → 脚本本体，不要删也不要改
两个文件必须放在同一个文件夹里。

【怎么用？】
第 1 步：双击“一键导出.bat”。
第 2 步：它会自动打开一个 Edge 窗口，里面是 DeepSeek 首页。
        如果这是你第一次用，请在这个 Edge 窗口里登录你的 DeepSeek 账号。
        （登录状态会保留，以后不用再登）
第 3 步：登录后，打开你要导出的那个对话页面。
        注意：要确保这个对话页面在 Edge 里是打开状态。
第 4 步：回到刚才那个黑色窗口，按提示输入文件名，回车。
        脚本会自动滚动页面、抓取全部对话、保存成 TXT。
第 5 步：导出完成后，终端会告诉你文件保存在哪里。

【文件保存到哪里？】
默认保存到：D:\对话存档\
如果该文件夹不存在，脚本会自动创建。

如果你的电脑没有 D 盘，请用记事本打开 export_chat.py，
找到这一行：
    SAVE_DIR = r"D:\对话存档"
改成你想要的路径，例如：
    SAVE_DIR = r"C:\对话存档"

【常见问题】
Q: 双击 .bat 后提示“没有检测到 Python”怎么办？
A: 会弹出 Python 官网下载页，下载安装时记得勾选 “Add Python to PATH”。
   装完后重新双击“一键导出.bat”。

Q: 提示“没有找到 DeepSeek 对话标签页”？
A: 确保那个带调试端口的 Edge 里，已经打开了要导出的对话页面，
   并且网址是以 chat.deepseek.com/a/chat/s/ 开头的。

Q: 导出的内容不全？
A: 重新运行一次脚本，它会重新滚动加载所有历史消息，再抓一遍。

Q: 导出文件里【我】和【AI】分得对吗？
A: 脚本会按页面上的消息顺序标记，正常情况下一问一答交替出现。

【注意】
- 别手动关掉脚本打开的 Edge 窗口，让它自己跑。
- 别改 export_chat.py 里的选择器（除非你知道自己在做什么），
  否则可能抓不到消息。
- 如果 DeepSeek 网页改版了，脚本可能会失效，需要重新调整抓取规则。
